# 《流萤来了哦》V1 制作说明与问题清单

## 当前结果

已完成完整 V1 的角色设定、素材制作、时间轴与二维合成。采用 GPT image 绘制 + Python 二维合成 + FFmpeg 封装的技术路线，工程中提供生成图、独立透明素材、完整时间轴、运行脚本与原始音轨来源。原片的音乐与音轨保持原样。视频由有限姿势循环、镜头变换与文字/粒子动效组成，不依赖重新生成整段 AI 视频。

V1 的画面采用米白底、暖褐轮廓、薄荷绿与黑白服饰。标题画面延续原作的彩色爆发构图；普通段使用 Q 版人物、少量色块、夸张表情、气泡与拟声大字。流萤保持银白至浅绿的长发、黑色发箍与羽叶饰品、白绿黑服饰；星保持灰发、金眼、黑灰金外衣，并承担左侧反应角色。萨姆用银色装甲与绿色面甲作为短暂反差彩蛋。

这里的动作是按原片时间点重新组织的有限姿势演出，并非逐帧复刻原动画。角色在全片主镜头中已替换；原作音乐与重要镜头布局继续作为基础。

## 素材清单与 GPT image 使用范围

进行了六次 GPT image 绘制：1 张统一角色设定图，3 张流萤/互动姿势图集，1 张星与萨姆支持图集，1 张标题背景。四张姿势图集分离成 48 个透明素材，包含主角姿势、唱歌嘴型、星的反应、双人合照、萨姆与变身器等。分离只做裁切、透明边界整理与合成适配，角色本体绘制来自 GPT image。

所有新增人物与标题主图均采用上述 AI 绘制结果。镜头排列、有限姿势切换、微小平移/旋转、键盘与门的线条、气泡、速度线、萤光、照片墙、文字与片尾由合成脚本完成。完整提示词保存在 `imagegen_prompts.json`，素材与原图位置保存在 `assets/manifest.json`。重新渲染会直接读取保存素材，无需再次调用模型。

星萤关系以旁观反应、分享蛋糕、合照和招呼表现，未增加独立恋爱剧情。萨姆以短暂换形与小道具承担机械身份笑点；暗底段使用萤光和星星保持温暖梦境氛围。70/20/10 作为创作重心，未将其机械换算为严格镜头时长。

## 当前版本的占位与问题

没有使用整段空白、未替换原角色或“稍后补视频”的占位。以下动作在 V1 使用有限素材作为简化替代：

1. 约 0:37–0:39 的门边招呼使用通用鞠躬/到场姿势，尚未绘制准确的扶门姿势。
2. 奔跑和走路使用各两张关键姿势；少量短动作依相似原片轮廓匹配到通用姿势。快速切换的手势与重心并不总能逐个对应原作。
3. 旋转、浮空、挥手采用整张图的有限变换，尚未拆分发丝、裙摆和关节。约 3:02–3:30 的长循环尤其适合 V2 增补。
4. 歌唱只使用三张表情/嘴型素材；没有逐音节 lip-sync。少量姿势之间的领饰、发丝与手部细节会有图集生成差异。
5. 拟声词由原片颜色/画面样本匹配；未逐帧人工核对全部日语气泡、所有拟声词和瞬间文字。中文气泡为主题化重写，因此不能当作原音内容的字幕。
6. 原作复杂叠影、数个高速变形、具体火焰/冲击形状和末段缩放曲线采用简化合成。V1 保留主要框架与进入时间，未逐像素复刻。
7. 部分放大特写和后排排列有意保留原作的画面边缘裁切；图集内的全身人物已检查裁切完整性。小角色较多的镜头仍需精修遮挡关系。
8. 角色图集比原作的纯色简笔画更精细，仍带少量模型生成的柔和阴影；后续可统一成更少的平涂色块。
9. 成片为 1080p 封装，内部二维合成画布是 720p；细线与放大特写的分辨率尚有提升空间。

## 同步、质量与复现检查

原片视频长度 301 秒，共 9,021 帧；AAC 音频长度约 301.0985 秒。合成以原片视频流作为时间载体，新画面覆盖原片内容；`overlay=ts_sync_mode=nearest` 将新画面逐帧对应回原片 PTS，并复制完整原 AAC 数据。

实际导出核验结果见 `verification.json`：其中包含视频总帧数、逐帧 PTS 最大误差、音轨 packet hash、尺寸、时长与输出文件 SHA-256。已检查完整素材库和 36 个代表镜头；最终编码视频另取样检查。音乐和整体时间轴没有为适应素材而拉伸或移动。

本次成片核验通过：封装总时长 **301.0985 秒**，尺寸 **1920×1080**，视频 **9,021 帧**；与原片逐帧 PTS 最大误差为 **0 秒**；原片与成片 AAC packet SHA-256 均为 `6324750fc81ed2fbb3737c54bce41b23afe164868012b20d426b9121845e8fc9`。最终编码视频抽取了 20 个跨全片的取样画面检查。
